## ⚙️ How I Work

- **Clean architecture first.** Clear layers, thin controllers, testable business logic.
- **Security by default.** JWT auth, RBAC, validation and structured logging from day one.
- **Understand the layer below.** ORMs when they help, raw SQL and stored procedures when they matter.
- **Ship and maintain.** Dockerized, deployed and monitored, not just "works on my machine".
